# Competitive positioning hypothesis

TRAVESÍA should not claim that maps, itineraries, expense splitting, companion chat or travel journals are unique. A testable position is **playful world exploration backed by transparent trip decisions**.

## Experience pillars
1. A full-body 3D companion that greets, points and walks along an interactive world rather than sitting in a square avatar or generic chat box.
2. Map-driven discovery linked directly to practical plans, transparent budget assumptions and source-labelled weather/flight signals.
3. Portal Run and unlockable companion/destination interactions make exploration feel like a game, while the planning UI stays legible.
4. The optional travel-video storyboard transforms selected visual moments into a concise shot list/caption plan; it is not misrepresented as an automatic video editor.

## Validation plan
Compare a clickable prototype against conventional itinerary planners in task-based tests: discover a destination, build a four-day budget draft, understand what is live, invite a companion, and complete Portal Run. Measure task completion/time, confusion about demo vs live data, chat usefulness, accessibility and return intent. Avoid asserting that a feature is unique without a current competitor audit.
