# TRAVESÍA cinematic finish v3

## Exact visual corrections
- Bloop remains the original aqua octopus animal, but the fixed bottom-right control is now transparent and 48 px desktop / 42 px mobile (38 px on narrow phones). The SVG illustration is only slightly larger than the hit target so its tentacles are not clipped. Pointer movement still tracks the eyes; clicking makes Bloop look toward the chat panel, blink and bounce.
- Portal Run is restyled as a bright tropical island/travel postcard diorama: turquoise sky and lagoon, warm sun, layered hills, moving cloud/route/card elements, cursor-led perspective and a photographic destination portal. The dark orbital/planet science presentation is suppressed. The seven-charm game, 30-second timer, score and personal best remain.
- Explore retains the selected destination preview inside the map and six destination postcards below it. The offline atlas now responds to pointer movement with a subtle camera shift while markers and selection remain clickable.
- The story chapters now use local destination photography (Goa, Kyoto and Rome), and feature cards have stronger depth, light and hover response.

## Run
Extract the ZIP, open `TRAVESÍA` in VS Code and run `run_windows.bat`. Use Ctrl+Shift+R once after replacing an older project folder to clear stale browser assets.

Reduced-motion preferences are respected.
