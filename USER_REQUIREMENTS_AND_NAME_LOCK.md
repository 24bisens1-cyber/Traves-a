# TRAVESÍA name and product requirements

Use the name **TRAVESÍA** consistently. The tagline is **The World Is Yours to Explore.** Keep one global travel experience (not a disconnected collection of screens) centred on playful world discovery and practical trip planning.

## Visual direction
- Premium, colourful, cinematic 3D ambience with layered parallax, cursor-responsive lighting and click-triggered reactions.
- Real full-body 3D companion, not a square avatar. Default mascot: original soft rounded teal plush octopus Bloop based on the visual style of the user's private references, not a copied character.
- Bloop stays stationary by default. Explicit clicks trigger hello/wave; destination selection triggers a walk/turn/greet sequence; the studio offers deliberate clip controls.
- A true visible world map fills the former blank globe region. Portal Run is interactive and playable.
- Keep mobile layouts responsive, support keyboard interactions and reduced motion.

## Product scope
Destination discovery, Trip Studio, Trip Pulseboard, mobility, stays/experiences, squad planning, shared trips/expense split, companion studio, account/security, AI companion, and optional travel-video storyboard. Civic Pulse, Nagpur-specific civic reports/routes/data are removed.

## Content and claims
Use original/licensed content. Do not bundle unlicensed characters from major franchises. Keep all provider secrets server-side. Never invent live prices, reservations, weather or current provider availability. Explain that storyboard output is text analysis of sampled frames, not audio transcription or automatic rendered video.
